# gorfednet profile

The public GitHub profile of Michael McArthur: `README.md` (shown on github.com/gorfednet) and `RESUME.md`. Prose and links only.

- Every word a visitor reads follows `docs/content-guidelines.md` in `gorfednet/.github` (read from `origin/main`). Copy changes go through the `copy` skill.
- Every change is a branch and a pull request. Ship-bot merges a pull request labelled `ready-to-merge` once its checks and the Claude review are clean.
- Every open pull request carries a `## Next` section in its body with `- [ ]` lines. Any turn that leaves the PR open rewrites it.
- Review house rules: `REVIEW.md`. Open PRs and red mains are in `STATUS.md` on the `status` branch of `gorfednet/.github`.
